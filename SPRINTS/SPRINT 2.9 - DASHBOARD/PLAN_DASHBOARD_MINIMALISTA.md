## 🎯 LOS 4 WIDGETS ESTRATÉGICOS

### **1. CRONOGRAMA VIVO - Timeline Maestro** 📅 ⭐⭐⭐⭐⭐
**El Corazón del Dashboard - Widget Principal**

#### **Concepto:**
Un timeline interactivo que muestra TODOS los proyectos en una línea de tiempo continua (pasado → presente → futuro), con toda la información crítica integrada.

#### **Funcionalidades:**

**Vista de Timeline:**
- ✅ **Eje temporal horizontal** (pasado ← HOY → futuro)
- ✅ **Línea por proyecto** con barra de progreso visual
- ✅ **Hitos marcados** (inicio, hitos intermedios, fin)
- ✅ **Indicador "HOY"** siempre visible
- ✅ **Zoom** (vista semanal, mensual, trimestral)
- ✅ **Scroll horizontal** infinito

**Información Integrada por Proyecto:**
- ✅ **Nombre y progreso** (%)
- ✅ **Estado de salud** (🟢 Saludable | 🟡 Atención | 🔴 Crítico)
- ✅ **Alertas tempranas** (⚠️ contador de alertas)
- ✅ **Riesgos detectados** (tipo y severidad)
- ✅ **Presupuesto** (gastado vs total)
- ✅ **Dependencias** (líneas conectoras entre proyectos)
- ✅ **Equipo asignado** (avatares)
- ✅ **Acciones sugeridas por IA** (✨ icono)

**Resumen Global (Footer del Widget):**
- ✅ **Total proyectos activos**
- ✅ **Progreso promedio**
- ✅ **Proyectos en riesgo**
- ✅ **Proyectos completados este mes**
- ✅ **Botón "Acciones Sugeridas"** → Abre panel con recomendaciones IA

**Interacciones:**
- ✅ **Click en proyecto** → Abre modal con detalles completos
- ✅ **Hover** → Tooltip con información extendida
- ✅ **Drag & drop** → Reprogramar fechas (con confirmación)
- ✅ **Click en alerta** → Muestra detalles y acciones
- ✅ **Click en hito** → Muestra información del hito

**Indicadores Visuales:**
- ✅ **Barra de progreso** con gradiente (verde → amarillo → rojo según salud)
- ✅ **Líneas de dependencia** entre proyectos relacionados
- ✅ **Marcadores de hitos** (◆ diamantes en timeline)
- ✅ **Zona de riesgo** (fondo rojo suave si hay problemas)
- ✅ **Predicción IA** (línea punteada mostrando proyección)

**Datos Mostrados:**
```typescript
interface ProyectoTimeline {
  id: string
  nombre: string
  progreso: number // 0-100
  salud: 'saludable' | 'atencion' | 'critico'
  fechaInicio: Date
  fechaFin: Date
  fechaFinReal?: Date // Predicción IA
  hitos: Array<{
    id: string
    nombre: string
    fecha: Date
    completado: boolean
  }>
  alertas: Array<{
    tipo: string
    severidad: 'baja' | 'media' | 'alta' | 'critica'
    mensaje: string
  }>
  riesgos: Array<{
    tipo: string
    probabilidad: number
    impacto: string
  }>
  presupuesto: {
    total: number
    gastado: number
    porcentaje: number
  }
  equipo: Array<{
    id: string
    nombre: string
    avatar: string
  }>
  dependencias: string[] // IDs de proyectos
  sugerenciasIA: Array<{
    tipo: string
    mensaje: string
    accion: string
  }>
}
```

### **2. MI DÍA - Centro de Comando Personal** 🎯

#### **Concepto:**
Vista ultra-compacta de las tareas del usuario actual, enfocada en lo que debe hacer HOY.

#### **Funcionalidades:**

**Estadísticas Rápidas:**
- ✅ **Completadas hoy** (con número)
- ✅ **En progreso** (con número)
- ✅ **Pendientes** (con número)

**Próxima Tarea:**
- ✅ **Título de la tarea**
- ✅ **Prioridad** (badge con color)
- ✅ **Tiempo estimado**
- ✅ **Proyecto al que pertenece**

**Acciones:**
- ✅ **Botón "Nueva Tarea"** → Abre modal de creación rápida
- ✅ **Click en "Próxima"** → Abre detalles de la tarea
- ✅ **Ver todas mis tareas** → Navega a vista completa

**Diseño:**
- Card compacto (1/3 del ancho)
- Números grandes para estadísticas
- Próxima tarea destacada
- Colores semánticos (verde, azul, gris)

---

### **3. EQUIPO - Mapa de Carga en Tiempo Real** 👥

#### **Concepto:**
Vista instantánea del estado del equipo completo, mostrando disponibilidad y alertas de sobrecarga.

#### **Funcionalidades:**

**Estadísticas de Carga:**
- ✅ **Disponibles** (🟢 verde) - Personas con capacidad
- ✅ **Carga Normal** (🟡 amarillo) - Personas en rango óptimo
- ✅ **Sobrecargados** (🔴 rojo) - Personas con exceso de trabajo

**Alertas de Acción:**
- ✅ **Mensaje de alerta** si hay sobrecarga
- ✅ **Sugerencia específica** (ej: "Redistribuir carga de María")
- ✅ **Botón de acción** → Abre herramienta de redistribución

**Acciones:**
- ✅ **Ver Mapa Completo** → Abre vista detallada con todos los miembros
- ✅ **Click en alerta** → Muestra opciones de redistribución

**Diseño:**
- Card compacto (1/3 del ancho)
- Números grandes con colores semánticos
- Alerta destacada si hay problemas
- Indicador visual de salud del equipo

### **4. ASISTENTE INTELIGENTE - IA Proactiva** 🤖

#### **Concepto:**
Widget de IA que analiza toda la información y presenta 3-5 sugerencias accionables del día, priorizadas por impacto.

#### **Funcionalidades:**

**Sugerencias Inteligentes:**
- ✅ **Alertas de riesgos** con acciones sugeridas
- ✅ **Oportunidades detectadas** (ej: equipo disponible para nuevo proyecto)
- ✅ **Optimizaciones** (ej: reuniones evitables)
- ✅ **Predicciones** (ej: proyecto se retrasará en 3 días)

**Cada Sugerencia Incluye:**
- ✅ **Icono descriptivo** (⚠️ alerta, ✨ oportunidad, 📊 optimización)
- ✅ **Título claro** del problema/oportunidad
- ✅ **Descripción breve** de la situación
- ✅ **Acción sugerida** específica
- ✅ **Botones de acción** (Aplicar, Ver Detalles, Descartar)

**Búsqueda Semántica Global:**
- ✅ **Barra de búsqueda** integrada en el widget
- ✅ **Búsqueda con IA** (lenguaje natural)
- ✅ **Resultados contextualizados**
- ✅ **Acceso rápido** a cualquier información

**Tipos de Sugerencias:**
```typescript
interface SugerenciaIA {
  id: string
  tipo: 'alerta' | 'oportunidad' | 'optimizacion' | 'prediccion'
  severidad: 'baja' | 'media' | 'alta' | 'critica'
  titulo: string
  descripcion: string
  entidad: {
    tipo: 'proyecto' | 'tarea' | 'equipo' | 'reunion'
    id: string
    nombre: string
  }
  accionSugerida: string
  impacto: string // ej: "Ahorra 2 horas", "Evita retraso de 3 días"
  acciones: Array<{
    tipo: 'aplicar' | 'ver' | 'descartar'
    label: string
    handler: () => void
  }>
}
```

**Diseño:**
- Widget ancho (full width)
- Lista de sugerencias con scroll
- Cada sugerencia es una card compacta
- Botones de acción claros
- Barra de búsqueda destacada

interface ProyectoTimeline {
  // Básico
  id: string
  nombre: string
  descripcion: string

  fechaInicio: Date
  fechaFin: Date
  fechaFinProyectada: Date // IA prediction
  
  // Progreso
  progreso: number // 0-100
  salud: 'saludable' | 'atencion' | 'critico'

  hitos: Array<{
    id: string
    nombre: string
    fecha: Date
    completado: boolean
    tipo: 'inicio' | 'intermedio' | 'fin'
  }>
  
  // Alertas y Riesgos
  alertas: Array<{
    id: string
    tipo: 'retraso' | 'presupuesto' | 'calidad' | 'equipo'

    mensaje: string
    fechaDeteccion: Date
  }>
  
  riesgos: Array<{
    id: string
    tipo: string
    probabilidad: number // 0-100
    impacto: 'bajo' | 'medio' | 'alto' | 'critico'
    descripcion: string
  }>
  
  // Recursos
  presupuesto: {
    total: number
    gastado: number
    porcentaje: number
    alertaPresupuesto: boolean
  }
  
  equipo: Array<{
    id: string
    nombre: string
    avatar: string
    rol: string
  }>
  
  // Dependencias
  dependencias: Array<{
    proyectoId: string
    tipo: 'bloqueante' | 'relacionado'
  }>

  sugerenciasIA: Array<{
    tipo: string
    mensaje: string
    accion: string
    impacto: string
  }>
  
  // Estadísticas
  tareas: {
    total: number
    completadas: number
    enProgreso: number
    bloqueadas: number
  }

## 🎯 INTERACCIONES DEL CRONOGRAMA

### **1. Vista General:**
- Scroll horizontal para navegar en el tiempo
- Zoom in/out (semanal, mensual, trimestral)
- Filtros: Todos, En Riesgo, Completados, Por Departamento

### **2. Por Proyecto:**
- **Hover:** Tooltip con información extendida
- **Click:** Abre modal con detalles completos
- **Drag:** Reprogramar fechas (con confirmación)
- **Click en alerta:** Muestra detalles y acciones sugeridas
- **Click en hito:** Información del hito y tareas asociadas

### **3. Acciones Globales:**
- **"Acciones Sugeridas":** Abre panel lateral con todas las recomendaciones IA
- **"Agregar Proyecto":** Crea nuevo proyecto
- **"Exportar Timeline":** Descarga imagen o PDF
- **"Vista Gantt":** Cambia a vista Gantt tradicional
